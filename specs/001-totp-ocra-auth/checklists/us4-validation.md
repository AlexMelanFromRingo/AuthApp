# Валідація US4: міграція ключів

**Статус**: автоматична частина пройдена; e2e-цикл очікує дві інсталяції

Автоматичні перевірки (виконано 2026-06-09, MigrationTest у :core-crypto):

- [x] Round-trip: seal → open відновлює маніфест байт-у-байт
- [x] Неправильна парольна фраза → MigrationOpenException без деталей
- [x] Пошкоджений шифротекст (1 біт) → відмова (GCM-автентифікація)
- [x] Квитанція: MAC нового пристрою = очікуваному на старому; підробка 1 біта → провал
- [x] Кадри: розбирання в довільному порядку, дозбирання пропущеного, ігнорування повторів і чужих пакетів
- [x] Кругова серіалізація URI квитанції

Сценарії приймання зі spec.md (потрібні 2 інсталяції / емулятор + пристрій):

- [ ] 1. Експорт із парольною фразою → пакет не читається без фрази
- [ ] 2. Імпорт на чистій інсталяції → токени відновлено, коди ідентичні
- [ ] 3. Неправильна фраза при імпорті → відмова, нічого не імпортовано
- [ ] 4. Сканування квитанції на старому пристрої → дозвіл штатної деактивації; після — токени не генерують кодів
- [ ] 5. Відмова від підтвердження → токени залишаються робочими
- [ ] 6. Примусова деактивація без квитанції → лише після двох підтверджень
